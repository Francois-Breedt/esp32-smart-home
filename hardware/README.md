# Hardware files

Add the PCB source project, schematic, fabrication exports, assembly drawings, and bill of materials here.

Suggested organization:

```text
hardware/
├── pcb/
│   └── rev-a/
├── schematics/
│   └── rev-a/
└── bom/
    └── rev-a.csv
```

Use a revision folder when the board changes. Do not upload manufacturer order credentials or other private information.
